# Research bundle

These files are the executable boundary between research and implementation:

- `architecture.json` defines one central input writer, five advice-only policies, and recoverable transition semantics.
- `sources.json` records evidence tier, license decision, approved use, immutable revision, and limitations.
- `cartridges.json` separates the stock qualification cartridge from the private derived compatibility cartridge.
- `knowledge.json` lists four generated, cartridge-authoritative datasets and three deferred secondary sources. Only the four private, reconciled datasets are runtime-eligible.
- `acceptance.json` defines implementation and campaign gates with allowed evidence classes and numerical targets.
- `evidence.json` contains artifact receipts only. It intentionally contains no synthetic substitute for operational evidence.
- `transitions.json` defines 25 real-emulator transition scenarios.

The JSON is validated by `src/research.js`. All seven implementation gates now pass, so `npm run check` reports `phase: "implementation-ready"` and `playerImplementationAllowed: true`. Campaign qualification remains separate.

ROMs, SRAM, savestates, raw captures, and proprietary generated bytes do not belong in this repository. The four full datasets stay under ignored `private/knowledge/`; this bundle records only their source/generator revisions, digests, sizes, reconciliation counts, and private receipt digest.

The real-mGBA ledger contains threshold-passing receipts for 10,000/0 atomic observations, 100/0 exact snapshot roundtrips, 100/0 Viridian Mart roundtrips, and one complete 25/0 modal-transition corpus. Full traces, save catalogs, content-addressed seeds, and the exact private suite remain private; the public receipt binds their suite and trace SHA-256 values. Single-scenario diagnostics remain explicitly non-promotable. See `docs/EMULATOR-EVIDENCE.md` for execution semantics and reproduction commands.
