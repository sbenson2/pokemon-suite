# Third-party material

Original Pokémon Suite code, documentation, and the neutral SVG icons under `pokemon_suite/static/assets/suite` are provided under the root MIT license. That grant covers only rights held by the project contributors. It does not relicense third-party code, photography, game content, or trademarks.

- Cartridge meshes by Bob, ewaldc2028, littlengvfx, SGLilac and maxns1980 retain CC BY 4.0, including the modified Crystal mesh. Sources, changes and attribution are in [licenses/cartridge-models/README.md](licenses/cartridge-models/README.md) and Settings → Support → Cartridge Credits. Commercial label textures from the model downloads are excluded.
- PokéAPI-derived factual catalogs retain the upstream notice in [licenses/POKEAPI-BSD-3-CLAUSE.txt](licenses/POKEAPI-BSD-3-CLAUSE.txt). See [DATA_SOURCES.md](DATA_SOURCES.md) for sources and transformations.
- Hardware photographs retain their source and license details in `pokemon_suite/static/assets/pokemon/hardware/SOURCE.md` and the in-app Settings credits link. Evan-Amos's SP and Micro photos and their visual adaptations retain CC BY-SA 3.0; the other five have public-domain/CC0 grants. These terms are separate from the app's MIT license.
- The libretro API header contains its upstream copyright/license notice in `native/libretro/libretro.h`.
- The retained Switch integration includes `native/suite-switch/Ryujinx-LICENSE.txt`.
- The source release includes no emulator binaries. The Mac app bundles one: a WebAssembly build of mGBA (MPL-2.0) and its wrapper (MPL-2.0), with the license text, source revisions and the exact shim source in [licenses/mgba](licenses/mgba/README.md). melonDS DS/GPL-3.0, Azahar/GPL, and the selected Ryubing/.NET/Cecil distributions have their own source, notice, and dependency requirements if later bundled. The libretro header's MIT license does not cover emulator cores.
- The Mac app also bundles the optional wireless-trading radio (`Runtime/RadioHost`): QEMU, a Linux kernel, Alpine Linux packages, Realtek firmware, the pokeldn relay (AGPL-3.0) and the LDN library (GPL-3.0). Its notices ship beside it in `Runtime/RadioHost-licenses`, and the complete corresponding source is attached to every release as `pokemon-suite-radio-sources-<version>.tar.gz`. See [licenses/radio](licenses/radio/README.md).
- The public exporter excludes game PNGs, Nintendo boot footage, vendor decompilation data (including mini-printf in that unused tree), and Smogon set data. Local development copies of those materials are not covered by the project's MIT grant.
- Game artwork displayed at runtime is decoded from the user's ROM and remains third-party game content. The decoder's MIT license does not apply to its image output. No game asset downloads or external sprite hosts are part of that path.
- ROMs, firmware, keys, private adapter data, and saves remain local installation inputs. User ownership or local extraction alone should not be represented as blanket legal permission; applicable law and third-party terms still matter.

## Native macOS runtime distribution

Mac app builds add Python 3.13 from the pinned python-build-standalone release and Node.js 22 from nodejs.org. Exact versions, URLs and SHA-256 hashes are in `macos/runtime-lock.json`. Python's original licenses remain in its runtime tree; the upstream dependency notice set is also in `licenses/python-runtime` and copied beside the runtime. Node's complete upstream `LICENSE` accompanies its executable. The pinned Pillow wheel supplies desktop video conversion; its license and bundled dependency notices remain in its `dist-info/licenses` directory inside the Python runtime. These components retain their own terms; the Suite's MIT license does not replace them.

The macOS cartridge app icon is original project artwork generated by `macos/Assets/Icon.swift` under the project's MIT license.

## Mobile prototype dependencies

The locally bundled JavaScript runtime uses `@noble/hashes` 2.4.0 and `buffer`
6.0.3, including `base64-js` and `ieee754`; esbuild 0.28.2 is a development build
tool. Exact dependency versions and integrity checks are in
`native/ios/package-lock.json`. Their MIT and BSD notices are preserved in
`licenses/mobile-runtime` and copied into development app builds. The source
release excludes `node_modules`. Private device builds also embed the user's
local mGBA core and knowledge inputs; those are not included in the public source
release and are not relicensed by this project.

## Software update dependencies

Sparkle 2.9.6 retains its upstream license and third-party notices in the pinned framework and `licenses/Sparkle-LICENSE`. The framework includes its own installer and downloader components. TUF, securesystemslib, cryptography, cffi, pycparser, and urllib3 retain the notices in `licenses/update-runtime` and their bundled Python metadata. Exact Mac wheel versions, URLs, and checksums are in `macos/update-runtime-lock.json`; portable development pins are in `pokemon_suite/update-requirements.txt`.
