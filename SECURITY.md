# Security

If you find a security problem, please report it privately with the **Report a vulnerability** button on this repository's Security tab rather than in public. This is a one-person hobby project, so fixes are best effort and there's no promised response time.

Things worth reporting:

- anything that exposes the local service or the iPhone/iPad connection beyond your own devices
- anything that gets past update, model or ROM verification
- anything that lets untrusted input run code
